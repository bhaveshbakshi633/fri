Long-Term Memory


Friday remembers across sessions and devices.


  • Automatic extraction — "I'm a robotics engineer" → saved as fact
  • Categories — personal, work, preferences, relationships, routines
  • Relevance scoring — 5 signals: confidence, recency, frequency, category, keywords
  • Deduplication — won't save "likes coffee" 10 times
  • Context injection — relevant memories loaded into every conversation

2000 token budget: 300 system + 500 memory + 800 history + 400 tools

iOS Safari — Battle Tested


Every gotcha discovered and solved:

  • continuous:true broken → restart loop pattern
  • Audio autoplay blocked → pre-unlock on first gesture
  • Edge TTS Origin check → Vercel Python proxy
  • OPFS storage OOM → fetch→blob bypass
  • Recognition dies after result → new instance per session
  • Mic "ding" sound → 400ms initial discard
  • Background kills audio → visibilitychange handler

Design System


Orb States

  • 🟡 Yellow — waiting for wake word
  • 🟢 Green — listening for command
  • 🟣 Purple — thinking (LLM)
  • 🔴 Red — speaking (TTS)
  • Responds to mic volume

UI

  • 3-layer dark theme depth
  • Glassmorphism tab bar
  • Apple-style animations
  • 44px min touch targets
  • Safe area handling

Security


  • API keys — server only, never in client
  • Passphrase — PBKDF2 600K iterations
  • Database — per-user isolation in CouchDB
  • XSS — DOMPurify on all rendered content
  • CORS — strict origin whitelist
  • CSP — Content Security Policy headers
  • Rate limiting — per user + per IP

20-item hardening checklist, threat model documented
